# Sistema de Gestão de Concessionária (CRUD PHP)

Este é um projeto acadêmico de um sistema de gerenciamento para uma concessionária de veículos, desenvolvido para aplicar conceitos fundamentais de CRUD (Create, Read, Update, Delete) utilizando PHP e banco de dados MySQL.

A interface foi construída com Bootstrap 5, focando em usabilidade e design responsivo.

## Funcionalidades

O sistema gerencia cinco entidades principais integradas ao fluxo de negócios:

* Funcionários: Cadastro e listagem de vendedores.
* Clientes: Gestão de dados pessoais, CPF e endereços.
* Marcas: Registro de fabricantes.
* Modelos: Cadastro de veículos vinculado às marcas via chaves estrangeiras.
* Vendas: Módulo central que conecta cliente, funcionário e o veículo vendido.

## Tecnologias Utilizadas

* PHP: Lógica de back-end.
* MySQL: Banco de dados relacional.
* Bootstrap 5: Layout responsivo e componentes de interface.
* HTML5/JavaScript: Estrutura e validações básicas de front-end.

# Dealership Management System (PHP CRUD)

Academic management system project for a vehicle dealership, developed to apply fundamental CRUD concepts using PHP and MySQL.

## Features

* Employees: Registration and listing.
* Customers: Personal data, TAX ID (CPF), and addresses.
* Brands: Manufacturer registration.
* Models: Linked to brands via foreign keys.
* Sales: Module connecting customer, employee, and vehicle model.

## Tech Stack

* PHP / MySQL / Bootstrap 5 / HTML5 / JavaScript
